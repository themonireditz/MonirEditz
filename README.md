# MonirEditz - Video Editor Portfolio

A high-converting, responsive portfolio website for video editors and thumbnail designers built with React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn or pnpm

### Installation

1. Unzip the project files or clone the repository.
2. Open your terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the local development server:
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:3000` (or the port shown in terminal).

### Building for Production

To create an optimized production build:
```bash
npm run build
```

The output will be generated in the `dist` folder, ready to deploy to **Vercel**, **Netlify**, **GitHub Pages**, or any web host.
